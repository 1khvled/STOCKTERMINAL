How the license works

You get one license key at checkout and paste it once on the Activate page. The key is bound to this machine (fingerprint shown on the Account page).

When this machine is offline the terminal keeps working from a signed local entitlement file for 14 days after the last successful check - you are never locked out on a plane or during an outage.

Need a seat for a colleague, an invoice, or a refund? Everything runs locally, so the operator can re-issue, extend or revoke a key from the CLI or the admin console.
